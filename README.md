## Overview

A fitness coaching platform that uses personal data to inform workout and nutrition recommendations. The application connects tracking with tailored guidance, using React, Node.js and PostgreSQL.

## The challenge

Users struggled to stick with generic fitness plans that ignored their goals and progress.

## The solution

Personalized, data-driven coaching that recommends workouts and nutrition from each user’s goals and history.

## Key features

- Fitness activity tracking
- Personalized workout recommendations
- Nutrition planning

## Tech stack

React · Node.js · PostgreSQL

## Live

https://wealthy-fitness.vercel.app/

## Privacy

Client names and records are confidential. Every screen in this repository uses sample data, and source code that belongs to the client is not published.
